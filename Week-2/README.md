
# 🔐 Week 2 - Advanced Networking & Network Security

## 📚 Topics Covered

- Common TCP/UDP Ports & Services
- Routers, Switches & Firewalls
- Router vs Switch
- Network Security Basics
- Man-in-the-Middle (MITM)
- Denial of Service (DoS)
- Packet Sniffing

## 🔬 Practical Work

### Wireshark
- Captured live network traffic
- Analyzed DNS traffic
- Analyzed HTTPS/TLS traffic on TCP port 443
- Identified source and destination IP addresses

### Nmap
- Performed an authorized scan of `scanme.nmap.org`
- Used `nmap scanme.nmap.org`
- Used `nmap -sV scanme.nmap.org`
- Identified open ports and running services
- Performed service/version detection

### Cisco Packet Tracer
- Created a LAN using 2 PCs and 1 Switch
- Configured PC1: `192.168.1.10`
- Configured PC2: `192.168.1.11`
- Tested connectivity using Ping
- Achieved 0% packet loss

### MITM Concept Simulation
- Created a safe MITM network topology
- Victim: `192.168.1.10`
- Attacker: `192.168.1.20`
- Router: `192.168.1.1`
- Studied MITM risks and prevention methods
