
# 🔐 Week 6 – Web Security & Vulnerability Testing (VAPT Basics)

## 📌 About This Week

During Week 6 of my Cybersecurity Internship at **DG Interns Hub**, I learned about common web application vulnerabilities and performed basic vulnerability testing using DVWA, Burp Suite, and OWASP ZAP.

This week focused on understanding how web vulnerabilities work, identifying security weaknesses, and learning basic prevention methods.

## 📚 Topics Covered

- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Broken Authentication
- Security Misconfiguration
- OWASP Top 10
- Basic Vulnerability Assessment and Penetration Testing (VAPT)

## 🛠️ Tools Used

- Kali Linux
- Docker
- DVWA (Damn Vulnerable Web Application)
- Burp Suite Community Edition
- OWASP ZAP

## 💻 Practical Tasks Completed

**Task 1 – OWASP Security Concepts**

Studied SQL Injection, XSS, Broken Authentication, and Security Misconfiguration.

**Task 2 – Lab Setup**

Set up DVWA using Docker and configured Burp Suite and OWASP ZAP for testing.

**Task 3 – Web Vulnerability Testing**

- Practiced SQL Injection in DVWA.
- Tested Reflected XSS and Stored XSS.
- Captured and inspected HTTP requests and responses using Burp Suite.

**Task 4 – OWASP ZAP Scan**

Performed an automated scan on the local DVWA application and reviewed the identified security alerts.

## 📊 OWASP ZAP Scan Results

| Risk Level | Alert Types |
|---|---|
| High | 0 |
| Medium | 2 |
| Low | 5 |
| Informational | 3 |
| **Total** | **10** |

Some findings included missing Content Security Policy, missing anti-clickjacking headers, and insecure cookie settings.

## 📖 What I Learned

I learned how to identify basic web application vulnerabilities using security testing tools. I also gained practical experience with HTTP requests, vulnerability scanning, reviewing security alerts, and understanding possible mitigation methods.

## ⚠️ Challenges Faced

I faced some issues while setting up DVWA, configuring tools, and exporting the OWASP ZAP report from Kali Linux.

I solved these problems by checking Docker settings, verifying the application URL, and correcting file path and shared folder issues.
