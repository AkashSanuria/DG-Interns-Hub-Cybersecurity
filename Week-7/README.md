
# Week 7 – Web Application Security Testing (VAPT)

**Internship:** DG Interns Hub – Cybersecurity Internship  
**Submitted By:** Akash Sanuria  
**Intern ID:** DG/SEPTEMBER/CYBER/171

## Project Overview

During Week 7, I performed web application security testing using Burp Suite, OWASP ZAP, and Damn Vulnerable Web Application (DVWA).

The objective was to understand common web vulnerabilities, analyze HTTP requests and responses, and document security findings.

## Tools Used

- Kali Linux
- Burp Suite Community Edition
- OWASP ZAP
- DVWA
- Docker
- Firefox

## Tasks Completed

**Task 22 – Burp Suite Setup and Interception**
- Configured Burp Suite
- Captured HTTP requests and responses
- Tested requests using Burp Repeater

**Task 23 – Reconnaissance and Application Mapping**
- Identified application endpoints
- Analyzed GET and POST requests
- Examined input parameters

**Task 24 – Vulnerability Testing**
- Demonstrated SQL Injection
- Demonstrated Reflected XSS
- Demonstrated Stored XSS
- Tested invalid login handling
- Modified request parameters using Burp Repeater

**Task 25 – Directory and Endpoint Discovery**
- Performed OWASP ZAP Spider Scan
- Discovered 122 URLs
- Added 57 nodes
- Saved the ZAP session snapshot

**Task 26 – Vulnerability Assessment Report**
- Documented security findings
- Added practical evidence
- Explained potential security impacts
- Provided remediation recommendations
- Prepared the final PDF report and PowerPoint presentation

## Key Learnings

This week helped me understand how web application vulnerabilities are identified through practical testing. I improved my skills in request interception, parameter analysis, vulnerability verification, and security reporting.

## Challenges

I experienced tool configuration issues and an unresponsive OWASP ZAP Active Scan. I restarted my Kali Linux environment, restored the DVWA container, and completed endpoint discovery using a Spider Scan.

## Security Note

All testing was performed in my local DVWA lab for educational purposes. Automated scan observations were treated separately from manually demonstrated vulnerabilities. Sensitive session information should be removed before publishing screenshots.

## Conclusion

Week 7 improved my practical understanding of web application security testing and the importance of secure coding, input validation, and vulnerability documentation.
